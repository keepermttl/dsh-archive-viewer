# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 3.0.x   | ✅ |
| 2.0.x   | ⚠️ maintenance |
| < 2.0   | ❌ |

## Reporting a Vulnerability

This is a local developer tool. If you find a security issue, please open a
private GitHub advisory at:

https://github.com/keepermttl/dsh-archive-viewer/security/advisories/new

Please include:

- the affected version
- a minimal reproduction
- the impact you observed

I will try to respond within a few days.
